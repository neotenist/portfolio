The receipts.

When in doubt, vibe code it!

Every campaign needs the same asset in a dozen shapes: newsletter, landing page, social, homepage banner. Figma exports the sizes, but it can't write WebP, and it gives you no control over compression quality on PNG or JPEG. So every batch ended in Photoshop or some web converter to get the file sizes down.

I vibe coded a tool with Claude to remove that step. Drop in a PNG, JPEG or WebP, pick the formats you want out, and set the quality per format with a slider that shows the resulting file size as you move it. Then export all three at once. It's a single HTML file: drag it into a browser and it runs, no install and no account, which is why the rest of the team actually uses it.

This is the kind of AI use I argue for. Instead of having AI slop generated for you, you build yourself a real tool that fits the way you actually work.
