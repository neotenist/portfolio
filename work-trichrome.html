A local image converter — drop in PNG, JPG, or WEBP, batch-convert between formats, and compare file sizes side by side. Nothing leaves the browser.

Up to 40 images at once, each converted and measured in real time across all three formats, so the actual size trade-off is visible before exporting anything.

A genuinely useful tool I kept needing myself — asset prep that used to mean several browser tabs and manual exports is now one page.
